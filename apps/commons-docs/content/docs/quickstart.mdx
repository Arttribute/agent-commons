title: Quickstart
description: Create an agent and get a streamed answer back, in about five minutes.
---

Every path below ends in the same place: an agent you own, a session you can
resume, and a streamed reply. Pick the one that matches how you like to work.

<Tabs items={['CLI', 'TypeScript SDK', 'REST API', 'Web app']}>
  <Tab value="CLI">

<Steps>
  <Step>
    **Install**

    ```bash
    npm install -g @agent-commons/cli
    ```
  </Step>
  <Step>
    **Sign in**

    ```bash
    agc login
    ```

    `agc` starts an OAuth device flow: it prints a URL and a one-time code,
    opens your browser, and waits for you to approve. Credentials land in
    `~/.agc/config.json` (mode `0600`) and refresh themselves.

    For CI, skip the browser and use a project key instead:

    ```bash
    agc login --api-key csk_live_xxx
    ```
  </Step>
  <Step>
    **Create an agent**

    ```bash
    agc agents create \
      --name "Research Bot" \
      --instructions "You research topics and answer with sources." \
      --provider anthropic \
      --model claude-sonnet-4-6
    ```
  </Step>
  <Step>
    **Talk to it**

    ```bash
    agc chat --agent <agentId>
    ```

    Tokens stream as they arrive and tool calls appear inline. `agc chat` also
    exposes your working directory to the agent as local tools, so it can read
    and write files on your machine — add `--no-local` to turn that off, or
    `--computer` to give it a cloud box instead.

    One-shot instead of a REPL:

    ```bash
    agc run --agent <agentId> "Summarise this week's AI policy news"
    ```
  </Step>
</Steps>

Run `agc` with no arguments for an interactive menu of everything else.
Full command list: [CLI reference](/docs/cli).

  </Tab>
  <Tab value="TypeScript SDK">

<Steps>
  <Step>
    **Install**

    ```bash
    npm install @agent-commons/sdk
    ```
  </Step>
  <Step>
    **Create a client**

    ```typescript
    import { CommonsClient } from '@agent-commons/sdk';

    const commons = new CommonsClient({
      apiKey: process.env.COMMONS_API_KEY, // csk_live_… project key
    });
    ```

    `baseUrl` defaults to `https://api.agentcommons.io`. Create a key at
    [auth.agentcommons.io/platform](https://auth.agentcommons.io/platform) or
    with `agc keys create`.
  </Step>
  <Step>
    **Create an agent**

    ```typescript
    const { data: agent } = await commons.agents.create({
      name: 'Research Bot',
      instructions: 'You research topics and answer with sources.',
      modelProvider: 'anthropic',
      modelId: 'claude-sonnet-4-6',
    });
    ```
  </Step>
  <Step>
    **Stream a reply**

    ```typescript
    let sessionId: string | undefined;

    for await (const event of commons.agents.stream({
      agentId: agent.agentId,
      messages: [{ role: 'user', content: 'What is Agent Commons?' }],
    })) {
      if (event.type === 'token') process.stdout.write(event.content ?? '');
      if (event.type === 'final') sessionId = event.sessionId;
    }
    ```

    Pass that `sessionId` back on the next call to continue the conversation.
    If you would rather wait for the whole answer, use
    `commons.run.once({ … })`.
  </Step>
</Steps>

Every namespace and type: [SDK reference](/docs/sdk).

  </Tab>
  <Tab value="REST API">

<Steps>
  <Step>
    **Get a key**

    Create a project API key at
    [auth.agentcommons.io/platform](https://auth.agentcommons.io/platform).
    Keys look like `csk_live_…` and carry explicit
    [scopes](/docs/authentication#scopes).

    ```bash
    export COMMONS_API_KEY=csk_live_xxx
    ```
  </Step>
  <Step>
    **Create an agent**

    ```bash
    curl -X POST https://api.agentcommons.io/v1/agents \
      -H "Authorization: Bearer $COMMONS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Research Bot",
        "instructions": "You research topics and answer with sources.",
        "modelProvider": "anthropic",
        "modelId": "claude-sonnet-4-6"
      }'
    ```

    ```json
    {
      "data": {
        "agentId": "agent_abc123",
        "name": "Research Bot",
        "modelProvider": "anthropic",
        "modelId": "claude-sonnet-4-6"
      }
    }
    ```
  </Step>
  <Step>
    **Run it**

    ```bash
    curl -X POST https://api.agentcommons.io/v1/agents/run \
      -H "Authorization: Bearer $COMMONS_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "agentId": "agent_abc123",
        "messages": [{ "role": "user", "content": "What is Agent Commons?" }]
      }'
    ```

    Swap the path for `/v1/agents/run/stream` to get Server-Sent Events
    instead of a single blocking response.
  </Step>
</Steps>

Every route: [API reference](/docs/api).

  </Tab>
  <Tab value="Web app">

<Steps>
  <Step>
    **Sign in**

    Go to [agentcommons.io](https://www.agentcommons.io) and sign in with your
    Commons account.
  </Step>
  <Step>
    **Create an agent**

    Open **Studio → Agents → Create**. Name and instructions are the only
    required fields; the model defaults to a sensible standard-tier choice.
  </Step>
  <Step>
    **Chat**

    Click the agent to open a session. Responses stream, tool calls render
    inline, and files you drag in are attached to the run.
  </Step>
  <Step>
    **Give it more to work with**

    From the agent editor you can switch on platform tools, attach skills,
    connect a Google or GitHub account, point it at a knowledge space, and
    turn on a heartbeat so it works while you are away.
  </Step>
</Steps>

Screen-by-screen tour: [Web app guide](/docs/ui).
