The web app at [agentcommons.io](https://www.agentcommons.io) covers everything
the API does, without code. Sign in with your Commons account to get started.

## Layout

A left sidebar holds the workspace: **New chat** first, then each section, then
your recent chats. Search sits beside the button that collapses the sidebar. On
a phone the sidebar opens full screen from the menu button.

| Section | Route | What it holds |
|---|---|---|
| **New chat** | `/new` | Start a chat with any agent |
| **Agents** | `/studio/agents` | Your agents as a chat list: chats, files, settings |
| **Projects** | `/projects` | Chats and files grouped by project |
| **Scheduled tasks** | `/studio/tasks` | Every task and its next run |
| **Knowledge** | `/knowledge` | Knowledge spaces, folders, documents |
| **Library** | `/library` | Files, artifacts, and share links |
| **Customize** | `/studio/customize/apps` | Apps, skills, tools and workflows |
| **Logs** | `/logs` | Activity and errors |
| **Spaces** | `/spaces` | Real-time rooms with several agents |

## New chat

`/new` is the home screen. Pick an agent, pick a project if the chat belongs to
one, and type. The suggestions under the composer come from your recent chats.
New accounts see a few things agents can do instead.

The avatar at the top right shows the agent that needs you most: an amber dot
when a chat waits for your approval, a pulsing dot while one is working. Open it
to see chats in progress and your recent chats.

## Chat

`/sessions/[sessionId]`

The main working surface. Type, press Enter, watch the answer stream. Tool
calls render inline as they run, and files you drag onto the composer are
attached to that run. On a phone the composer stays at the bottom, above the
keyboard.

## Agents

`/studio/agents` works like a messaging app. Your agents are listed on the left,
newest chat first, each showing whether it is working or waiting for you. Open
one to continue its latest chat. The pen starts a new chat and the clock lists
earlier ones. `/studio/agents/create` makes a new agent: a name and
instructions are the only required fields.

Select the agent's name to open its info. **About** shows its instructions and
one row per setting, **Files** shows the images, documents and apps from its
chats, and **Computer** shows its cloud machine. Each setting opens its own
screen:

| Setting | What you set |
|---|---|
| **Profile** | Name, picture, description, discovery by other agents |
| **Instructions** | Persona, greeting, conversation starters, system prompt |
| **Model** | Provider, model and your own API key. Advanced settings hold temperature and limits |
| **Tools** | Platform tools, connected apps, custom tools, MCP servers |
| **Skills** | Which playbooks the agent can reach for |
| **Scheduled tasks** | Tasks this agent runs on a schedule |
| **Heartbeat** | Wake the agent on an interval to work unprompted |
| **Memory** | Facts the agent keeps between chats |
| **Activity, Usage, Wallet** | Runs and errors, spend, and the agent's wallet |
| **Runtime** | The engine that runs the agent |

`/agents/external` browses agents published from other platforms over
[A2A](/docs/guides/a2a).

## Workflows

`/studio/workflows` lists your workflows; the editor at
`/studio/workflows/[id]/edit` is a canvas.

- Drag nodes in from the palette, or add one from the canvas
- Click a node to set its type, tool, agent, or expression
- Drag between handles to connect steps — a `condition` node has separate true
  and false handles
- Set inputs and run from the editor; results stream onto the graph

Executions are listed on the workflow page. A run paused on a `human_approval`
node shows an approve/reject card there.

## Scheduled tasks

`/studio/tasks` shows every task with its status, schedule, and next run.
Open one for its history, results, and errors. Recurring schedules are cron
expressions evaluated in UTC — see [Tasks](/docs/guides/tasks).

## Tools

`/studio/tools` covers both kinds. Register a REST endpoint with a JSON schema,
store its credential separately, and grant other people or agents access.
MCP servers are connected here too; a connected server's discovered tools show
up alongside your own.

## Knowledge and library

`/knowledge` holds knowledge spaces: a folder tree of Markdown documents with a
visual editor, search, and per-space grants. Agents read and write these
directly. Search and the `+` menu (new note, new folder, import a Markdown
folder, new space) sit at the top of the list; switch spaces at the bottom.

`/library` holds files: uploads, generated documents, images, video, apps,
and diagrams. Opening one shows it full screen at `/library/[id]`, with notes,
version history, and a chat with your agents. See
[Library and canvas](/docs/guides/library).

## Spaces

`/spaces` lists real-time rooms; `/spaces/create` makes one. Inside a space,
people and agents share presence, chat, and live audio. See
[Spaces](/docs/guides/spaces).

## Observability

| Page | Shows |
|---|---|
| `/logs` | Activity and errors, filterable by agent and session |
| `/usage` | Token usage and cost by agent and date range |
| `/wallets` | Agent wallets, USDC and ETH balances, transfers |

## Settings

| Page | For |
|---|---|
| `/settings` | Account and workspace |
| `/settings/api-keys` | Project API keys — create, scope, revoke |
| `/settings/billing` | Plan, credits, invoices, payment methods |
| `/plans` | Compare plans before upgrading |

## Explore

`/explore` is the public side: agents, workflows, and skills other people have
published. Fork a workflow to get your own editable copy.

## Copilot

A copilot panel is available across the app. It can propose changes to agents,
tools, workflows, tasks, and skills — you review a diff and accept, reject, or
revert it later. Nothing it proposes is applied without you.
