Agent Commons gives an agent everything it needs to do real work: a model, a
toolbelt, memory, a place to keep files, a computer it can log into, a schedule,
a wallet, and a record of where every answer came from.

You can drive all of it from the web app, the `agc` CLI, the TypeScript SDK, or
plain HTTP.

<Callout>
  New here? The [Quickstart](/docs/quickstart) has an agent answering you in
  about five minutes.
</Callout>

## What an agent can do

| Capability | Where it lives |
|---|---|
| Chat with streamed tokens, tools, and attachments | [Agents](/docs/guides/agents) |
| Call your APIs, MCP servers, and built-in platform tools | [Tools & MCP](/docs/guides/tools-mcp) |
| Follow reusable, publishable playbooks | [Skills](/docs/guides/skills) |
| Read and write shared documents and files | [Knowledge & library](/docs/guides/knowledge) |
| Remember facts across sessions | [Memory](/docs/guides/memory) |
| Run multi-step graphs with approvals | [Workflows](/docs/guides/workflows) |
| Wake on a cron schedule or a heartbeat | [Tasks & scheduling](/docs/guides/tasks) |
| Get a persistent Linux box with a browser | [Computers](/docs/guides/computers) |
| Act as you in Google, GitHub, and Slack | [Connections](/docs/guides/connections) |
| Delegate to other agents over an open protocol | [A2A](/docs/guides/a2a) |
| Show its sources and export a signed bundle | [Provenance](/docs/guides/provenance) |
| Hold USDC and pay for what it uses | [Wallets](/docs/guides/wallets) |

## Thirty seconds of code

```typescript
import { CommonsClient } from '@agent-commons/sdk';

const commons = new CommonsClient({ apiKey: process.env.COMMONS_API_KEY });

const { data: agent } = await commons.agents.create({
  name: 'Research Bot',
  instructions: 'You research topics and answer with sources.',
  modelProvider: 'anthropic',
  modelId: 'claude-sonnet-4-6',
});

for await (const event of commons.agents.stream({
  agentId: agent.agentId,
  messages: [{ role: 'user', content: 'What changed in EU AI rules this month?' }],
})) {
  if (event.type === 'token') process.stdout.write(event.content ?? '');
}
```
