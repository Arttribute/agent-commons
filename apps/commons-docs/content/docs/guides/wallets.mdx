---
title: Wallets & Payments
description: Give an agent an on-chain wallet so it can hold USDC and pay for what it uses.
---

An agent can hold an EOA wallet on **Base Sepolia**. That lets it pay x402
challenges for metered APIs, settle with other agents, and receive payment for
its own work — without a human in the loop for every transaction.

<Callout type="warn">
  Base Sepolia is a **testnet**. USDC there has no real value. Treat this as
  the rails, not the bank.
</Callout>

| | |
|---|---|
| Chain | Base Sepolia (`chainId` `84532`) |
| Token | USDC — `0x036CbD53842c5426634e7929541eC2318f3dCF7e` (6 decimals) |
| Key custody | viem keypair, encrypted at rest |

<Callout type="info">
  Wallet USDC is unrelated to platform [credits](/docs/guides/billing).
  Credits pay Agent Commons for tokens and compute; USDC is the agent's own
  money for external services.
</Callout>

## Create a wallet

<Tabs items={['CLI', 'SDK', 'API']}>
  <Tab value="CLI">
```bash
agc wallet create --agent <agentId> --label Primary
agc wallet show    --agent <agentId>
agc wallet balance --agent <agentId>
```
  </Tab>
  <Tab value="SDK">
```typescript
const wallet = await commons.wallets.create({
  agentId,
  walletType: 'eoa',
  label: 'Primary',
});

const balance = await commons.wallets.balance(wallet.walletId);
// { address, chainId, native: '0.01', usdc: '25.000000' }
```
  </Tab>
  <Tab value="API">
```bash
curl -X POST https://api.agentcommons.io/v1/wallets \
  -H "Authorization: Bearer $COMMONS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "agentId": "agent_abc123", "walletType": "eoa", "label": "Primary" }'
```
  </Tab>
</Tabs>

`walletType: 'external'` registers an address you already control — pass
`externalAddress`. The platform can then read its balance but never signs for
it.

The first wallet becomes the agent's primary; `commons.wallets.primary(agentId)`
returns it.

## Funding

Send USDC to the wallet address on Base Sepolia, plus a little ETH for gas.
Base Sepolia ETH comes from the public faucets; USDC from Circle's testnet
faucet.

```bash
agc wallet balance --agent <agentId>
```

## Transfers

```bash
agc wallet send --agent <agentId> --to 0xrecipient… --amount 5 --token USDC
```

```typescript
const { txHash } = await commons.wallets.transfer(wallet.walletId, {
  toAddress: '0xrecipient…',
  amount: '5',
  tokenSymbol: 'USDC',
});
```

`amount` is a decimal string in whole tokens — `'5'` is 5 USDC, not 5 units.

## x402 payments

x402 is the `402 Payment Required` flow for paid HTTP APIs. Point the wallet at
a URL and it handles the challenge: request, read the challenge, sign the
payment, retry.

```bash
agc wallet x402-fetch --agent <agentId> --url https://paid.example.com/dataset
```

```typescript
const response = await commons.wallets.x402Fetch(agentId, {
  url: 'https://paid.example.com/dataset',
  method: 'GET',
  headers: { Accept: 'application/json' },
});
// { status, body }
```

This is what makes an agent able to buy the data it needs mid-run rather than
failing and asking you to subscribe.

## Safety

- **Fund for the job.** An agent can only spend what its wallet holds, so the
  balance is the spending limit. Keep it small and top it up.
- **Separate wallets for separate risks.** One agent, one wallet, one purpose.
- **Watch the ledger.** `agc wallet balance` and
  [provenance](/docs/guides/provenance) show what was spent and on what.
- **Private keys never leave the platform.** They are encrypted at rest and no
  endpoint returns them. There is no export — an agent's wallet cannot be
  recovered elsewhere, so treat it as a spending account, not a store of value.
- **Deactivate what you are done with**: `commons.wallets.deactivate(walletId)`.
